# Hinglish style guide

Use natural Roman-script Hindi with everyday English nouns: deadline, rent, client, file, packing, call. Narration follows the same register as dialogue but need not copy all spoken contractions. No Devanagari needed.

Canonical forms: main (I), mein (in), nahi, kyun, kyunki, haan, yahan, wahan, achha, thoda, zyada, poocha, dekha, chahiye, hoon, ho, hai, hain, tha/thi/the, gaya/gayi/gaye, kiya, liye, tumhe, mujhe, tumhara, apna. Use 'yeh' and 'woh' consistently, with 'is/uss' as grammar requires; prefer 'usne/uski' without doubled s. 'Chai' remains chai. No forced English apostrophes for Hindi plural forms.

Meera and Aarav use tum with each other. Parents receive aap; close friends use tum. Switches must be deliberate and local. Meera calls Shaila 'Ma'; Aarav calls his parents 'Ma' and 'Papa'. Aarav refers to Shaila as 'Aunty' in direct speech unless a later scene establishes otherwise.

English is natural for work specifics and some emotional evasions: 'It's fine', 'I said I'll handle it.' Do not automatically italicise English or Hindi. Use double quotation marks for dialogue; begin a new paragraph when speaker changes. Dialogue tags should be unobtrusive: kaha, poocha, bola. Avoid tagging every line with emotion. Text messages use block quotes in source Markdown; one sender per block, with attribution nearby.

Third-person limited: Aarav and Meera may infer each other's feelings, but the narration cannot confirm both minds inside one continuous scene. Scene breaks are '***'. Flashbacks have a clear physical trigger and a return to the current task. Never use omniscient 'dono jaante the' unless they have both stated it.

Domestic register: roti, dal, dabba, bartan, balcony, society office. Use Maharashtrian place context lightly; no stereotypes or unnecessary language performance. Dialogue need not translate familiar Hindi words. Avoid imported therapy phrases, slogans, repeated rhetorical questions and polished life lessons. Let awkward sentences remain awkward when a character would struggle.

Word-count method: split story body on whitespace after removing Markdown heading and divider lines. Hyphenated words count as one; Roman-script tokens count like English tokens. Publish the method with actual counts. Do not include copyright, descriptions, notes or reports in the story-body count.
