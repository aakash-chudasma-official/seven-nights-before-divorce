# Seven Nights Before Divorce

An original contemporary Indian novel in natural Roman-script Hinglish. Twelve chapters, 30,190 story words.

The illustrated static reader is in docs/. GitHub Pages uses main /docs. Publication is being configured.

The definitive story source is in chapters/. To rebuild reviewed content run python3 build_manuscript.py then python3 build_reader.py. Editing records and exact word counts are included.

Reading features: adjustable text size, light/dark/sepia themes, bookmarks, saved reading position and chapter navigation. Settings stay in the same browser/device. No login or payment integration.
